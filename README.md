# Демо-сайт кофейни «Тёплый угол»

Адаптивный сайт-визитка на HTML и CSS. Это вымышленный бизнес для портфолио; контакты, адрес, цены и отзывы указаны как демонстрационные данные.

## Как посмотреть

Откройте `index.html` в браузере. Для полноценного просмотра требуется подключение к интернету: фотографии и шрифты загружаются с Unsplash и Google Fonts.

## Перед публикацией

Замените демонстрационные адрес, телефон, соцсети, меню, цены и ссылку на карту на реальные данные заказчика. Убедитесь, что у вас есть право использовать выбранные фотографии.

## Публикация через GitHub Pages

1. Создайте новый публичный репозиторий GitHub.
2. Загрузите в него `index.html` и `style.css` из этой папки.
3. В настройках репозитория откройте **Pages**.
4. Выберите публикацию из ветки `main` и папки `/ (root)`, затем сохраните.
5. Через несколько минут GitHub покажет ссылку на сайт в разделе Pages.
