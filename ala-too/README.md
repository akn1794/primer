# Ala-Too Trails — демонстрационный сайт турагентства

Одностраничный адаптивный лендинг на HTML и CSS. Бренд вымышленный, а адреса, контакты, цены и отзыв приведены только для примера. Не выдавайте их за реальные данные.

## Просмотр

Откройте `index.html` в браузере. Для загрузки фотографий и шрифтов нужно подключение к интернету.

## Публикация как подпапка GitHub Pages

Загрузите `index.html` и `style.css` в отдельную папку репозитория, например `tours/`. Если GitHub Pages уже включён из корня репозитория, сайт будет доступен по адресу `https://<username>.github.io/<repository>/tours/`.

Перед работой с настоящим бизнесом замените описание туров, даты, цены, контакты и фотографии на подтверждённые заказчиком данные.
