# FORMA — демо-сайт барбершопа

Адаптивный сайт-визитка для вымышленной студии в Бишкеке. Цены, адрес, телефон и команда приведены только для примера.

## Просмотр

Откройте `index.html` в браузере. Фотографии и шрифты загружаются из интернета.

Перед использованием для настоящего бизнеса замените все демонстрационные данные, контакты, цены и фотографии на согласованные с заказчиком.
